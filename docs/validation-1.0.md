# Проверка MVP 1.0

Дата проверки: 18 октября 2026 года.

## Сборка и логика

- JDK 17.0.20.1, Gradle 8.11.1, Android Gradle Plugin 8.9.2, SDK 35.
- `assembleDebug` и `assembleRelease` выполнены успешно.
- `testDebugUnitTest`: 27 тестов, 0 ошибок, 0 падений, 0 пропусков.
- `lintDebug`: 0 ошибок. Два предупреждения относятся к закреплённой
  портретной ориентации, указанной в техническом задании.
- `assembleDebugAndroidTest`: тестовый APK успешно собран.
- `scripts/setup-cloud.sh` и `scripts/package-test-apk.sh` выполнены в облачной
  среде повторно. Подпись устанавливаемого APK проверена `apksigner verify`.
- В манифесте APK отсутствует разрешение `INTERNET`.

Модульные тесты проверяют календарные границы и високосный год, переходы
часовых поясов и летнего времени, перевод часов назад, длительное отсутствие,
все границы уровней, склонения, неизменные пороги наград, отсутствие дублей,
коррекцию даты, непересекающиеся периоды и длительную историю.

## Проверка на Android

Компактная сборка установлена и запущена на программном эмуляторе Android 9
(API 28), экран 432×936, плотность 180 dpi. Проверены русское приветствие,
выбор прошедшей даты начала и автоматическое открытие «Первой недели».
Вручную проверены счётчик 8 полных дней / текущий день 9, коллекция 3/16,
детали и дата награды, подтверждённые дни календаря, статистика, график,
карта активности и переключение тёмной/светлой темы. Скриншоты сохранены
в `/workspace/artifacts/`. Дополнительно проверен системный шрифт 150%:
онбординг прокручивается до кнопки, счётчик, навигация и карточки доступны.
Исправление цвета системной панели проверено на итоговом компактном APK.

В проекте есть 18 инструментальных тестов: 7 для Room/DataStore, 7 для
уведомлений, 4 для интерфейса и обработки некорректной даты устройства.
Повторный `ANDROID_SERIAL=emulator-5556 ./gradlew connectedDebugAndroidTest`
успешно завершён: **17 выполнено, 0 ошибок, 0 пропусков** (2 мин 21 с).
После добавления проверки сокращения завершённого периода повторно выполнен
весь класс уведомлений: **7 выполнено, 0 ошибок, 0 пропусков** (1 мин 21 с).
Итого успешно проверены 18 различных Android-тестов. Сохранены журналы
`test-results/android-full.log`, `test-results/android-notifications.log`
и XML-результаты модульных тестов. Последний HTML-отчёт находится в
`app/build/reports/androidTests/connected/debug/index.html`.

Первый запуск инструментального набора не выполнил ни одного теста:
`system_server` программного эмулятора завершился по таймауту финализатора,
установка оборвалась с `package: Broken pipe (32)`. Это сбой Android-образа
до запуска тестов приложения. Для повторной проверки уменьшено разрешение,
проверяется стабильность системы после полной загрузки.

Проверка на физическом телефоне и проверка разрешения уведомлений на
Android 13+ отдельно не считаются выполненными без результатов устройства.
WorkManager не гарантирует точную минуту доставки в энергосберегающем режиме.
