# Файлы приложения

- `day-by-day-1.0.apk` — ранее выпущенное приложение.
- `day-by-day-source.zip` — исходники выпущенной версии 1.0.
- `day-by-day-2.0-source.zip` — исходники версии 2.0 с кнопкой
  «Отметить употребление» и миграцией истории.

Установочного `day-by-day-2.0.apk` пока нет: для обновления установленной
версии без удаления её данных нужно восстановить исходный приватный ключ
подписи из прежней облачной среды. Новый ключ Android не примет.
Старое приложение на телефоне сохраните установленным.

Подробности и результаты проверок — в [README](../README.md)
и [validation.md](../docs/validation.md). Суммы файлов — в `SHA256SUMS.txt`.
