# День за днём

Автономный Android-трекер дней без алкоголя. Kotlin, Jetpack Compose, MVVM,
Room, DataStore, Navigation Compose и WorkManager. Android 9 (API 28) и новее.
Интерфейс на русском, тёмная и светлая темы. Аккаунт, сервер и интернет не нужны.

## Сборка в Android Studio

1. Откройте корень проекта в актуальной Android Studio с поддержкой AGP 8.9.2.
2. Выберите JDK 17 и установите Android SDK Platform 35 и Build Tools 35.0.0.
3. Дождитесь Gradle Sync и запустите конфигурацию `app` на устройстве API 28+.

В терминале с настроенным `ANDROID_HOME` и JDK 17:

```bash
./gradlew assembleDebug testDebugUnitTest lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
Это тестовая сборка с отладочной подписью. Для публикации нужен собственный
release-ключ; ключи и пароли в репозитории не хранятся.

В подготовленной облачной среде `bash scripts/package-test-apk.sh` создаёт
компактный APK с R8 и удалением неиспользуемых ресурсов:
`/workspace/artifacts/day-by-day-1.0.apk`. Он также подписан общедоступным
отладочным ключом Android и предназначен для тестирования, не для магазина.
Обычная `./gradlew assembleRelease` создаёт неподписанный APK для вашей подписи.

## Установка на телефон

Перенесите APK на Android-телефон и откройте его. При запросе Android разрешите
установку из выбранного источника. Либо включите USB-отладку и выполните:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Новые сборки можно установить поверх предыдущих при сохранении того же ключа.
Удаление приложения удаляет локальные данные. Облачного резервного копирования
в MVP нет; автоматическое резервное копирование Android отключено.

## Codex cloud

Среда каждой задачи уже изолирована: используйте существующий checkout,
не создавайте дополнительные Git worktree без явного запроса пользователя.

```bash
cd /workspace/without_alcohol
bash scripts/setup-cloud.sh
source scripts/cloud-env.sh
./gradlew assembleDebug testDebugUnitTest lintDebug
```

Скрипт хранит SDK, JDK и кеши в `/workspace`, проверяет контрольные суммы
инструментов и сохраняет TLS-проверку. Сторонние приватные сервисы и секреты
не требуются. Для первоначальной загрузки нужны разрешённые домены
`github.com`, `release-assets.githubusercontent.com`, `services.gradle.org`,
`dl.google.com`, `repo.maven.apache.org`, `plugins.gradle.org` и
`plugins-artifacts.gradle.org` (покрываются предустановкой менеджеров пакетов).

Для инструментальных тестов используйте подключённое устройство или эмулятор:

```bash
./gradlew connectedDebugAndroidTest
```

Опционально `WITH_EMULATOR=1 bash scripts/setup-cloud.sh` установит эмулятор
и образ API 28 для проверки минимальной версии. На Linux без `/dev/kvm` можно использовать `-accel off`;
программная эмуляция заметно медленнее. ADB требует доступный для записи
служебный каталог пользователя `.android`.

## Поведение и структура

- `domain/`: независимые от Android расчёты дат, уровней и достижений.
- `data/`: Room для периодов/наград, DataStore для настроек. Изменения истории
  и наград выполняются транзакционно.
- `ui/`: восемь экранов Compose, оригинальные векторные награды, навигация.
- `notifications/`: необязательные нейтральные уведомления через WorkManager.
- `TrackerViewModel`: связывает состояние, хранилище и UI; обновляет дату при
  открытии, возвращении, полуночи и изменении системных часов/часового пояса.

В день начала крупный счётчик показывает 0 полных дней, а текущий день — 1.
Закрытый период включает выбранный последний полный день; следующий начинается
не раньше следующего дня. Периоды не пересекаются, перерывы не засчитываются.
Награда хранится один раз и сохраняется при новом периоде. Явное исправление
даты начала пересчитывает награды, связанные с исправленным периодом.
При переводе часов назад счётчик не становится отрицательным, уже сохранённые
награды не исчезают. Сегодняшний день в календаре ещё не считается полным.

Разрешение уведомлений запрашивается только после включения соответствующей
настройки. При отказе приложение продолжает работать. По умолчанию уведомления
отключены, текст нейтрален; приватный режим скрывает подробности на экране
блокировки. WorkManager соблюдает ограничения энергосбережения Android, поэтому
доставка может произойти позже выбранного времени. Постоянного фонового таймера
нет. Приложение не запрашивает разрешение `INTERNET`, не содержит рекламы и
аналитики. Никакие медицинские результаты из числа дней не выводятся.
